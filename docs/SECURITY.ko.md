# 보안 안내

[English](SECURITY.md) · 한국어

## 신고

저장소의 **Security → Report a vulnerability** 비공개 신고 경로를 사용해 주세요.
영향받는 버전, 전제 조건, 가상 데이터를 사용한 재현과 영향을 알려 주세요.
공개 이슈에 악용 방법이나 실제 자격증명을 올리지 마세요.
비공개 신고 기능이 열려 있지 않다면 민감한 내용을 공개하지 말고
비공개 경로가 준비될 때까지 기다려 주세요.

개발자 프리뷰이며 응답 기한이나 장기 지원을 약속하지 않습니다.
현재 개발 버전과 최신 프리뷰를 대상으로 수정합니다.
의존성 감사는 검사한 환경에 대한 결과이며 보안 보증이 아닙니다.

## Duru 사용

자격증명은 애플리케이션에서 전달하고 토큰과 비공개 파일은 Git 밖에 두세요.
검증된 읽기·조건부 쓰기에는 내용 버전을 사용하세요.
EffectUnknown이면 변경이 이미 수행되었을 수 있으므로 확인 후 재시도하세요.

로컬 파일 격리는 Linux에서 강화되어 있습니다. Windows는 경로 검사 방식을 사용하며
동일한 파일 디스크립터 기반 격리를 보장하지 않습니다.
변경 잠금은 협력하는 클라이언트를 조정하며 무관한 OS 쓰기까지 조정하지 않습니다.
검증된 파일 내용을 버퍼링하므로 파일 크기에 비례해 메모리를 사용합니다.

계정 정책·문서 권한·스케줄·인덱싱은 Duru를 사용하는 애플리케이션의 책임입니다.
