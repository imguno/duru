# 기여 안내

[English](CONTRIBUTING.md) · 한국어

[README](../README.ko.md)에서 시작하고 변경하려는 동작을 먼저 재현해 주세요.
버그에는 패키지·Python 버전, 실행 명령이나 최소 코드, 기대 동작과 민감정보를
제거한 오류를 포함해 주세요. 확장 기능에는 지원 기능과 작은 실행 예제가 필요합니다.

## 로컬 검사

README의 개발 명령을 사용하세요. 작업 중에는 관련 테스트를 실행하고,
공유하기 전에 필요한 통합 검사를 완료하세요. 사용자 문서는 영문·한글을 함께
갱신해 주세요. CI는 코드 스타일·테스트·의존성 취약점·배포 설치를 검사합니다.
로컬 통과가 GitHub CI 실행을 의미하지는 않습니다.

자격증명은 외부에서 전달하고 내용 버전을 검증 가능하게 유지하세요.
URI·이름 규칙과 지원 기능을 설명해 주세요. 변경·스냅샷·파일 격리를 바꾸면
계약·경합 검사와 독립 리뷰를 포함하세요. Duru는 앱 스케줄러나 문서 권한 서비스를
제공하지 않습니다.

## 풀 리퀘스트

사용자에게 생기는 문제와 변경 후 동작, 검증 결과, 마이그레이션 요구사항을
설명해 주세요. 실제 토큰·비공개 문서·계정 DB·환경 파일·자격증명이 담긴 로그를
첨부하지 마세요.
